# Petit guide pour construire votre plan

## 1. Vérifier que votre sujet fonctionne

**Ce qui marche bien :**
- Un système de documentation précis (une base de données, une plateforme, un projet de numérisation, un catalogue raisonné)
- Une tension concrète entre deux logiques (ouverture vs. restriction, standardisation vs. contextualisation, conservation vs. accessibilité)

**Ce qui est trop vague :**

- « La digitalisation des musées » = trop vaste
- « Les métadonnées » = pas de réalisation à décrire

Vous avez votre sujet si vous pouvez nommer *un* dispositif, *une* institution, et *une* question critique ? 

## 2. Où chercher les sources

| Type de source            | Où chercher                                                  |
| ------------------------- | ------------------------------------------------------------ |
| Articles scientifiques    | Cairn.info, JSTOR, Google Scholar                            |
| Références fondatrices    | Bibliothèque universitaire                                   |
| Documentation technique   | Sites institutionnels, GitHub                                |
| Rapports professionnels   | ICOM, ICOM-CC, SMQ, Recommandations, actes de colloques      |
| Retours d'expérience      | Blogs muséaux, Medium, *Museum 2.0*, Posts de documentalistes, retours de projets |
| Études de cas canadiennes | Rapports annuels, mémoires de maîtrise                       |

**Astuce :** commencez par un article de synthèse récent (2018+), puis remontez ses références pour identifier les textes fondateurs.

## 3. Construire le plan

**Étape 1 : Décrire avant de juger**
Faites une fiche brute sur le dispositif : qui, quoi, quand, comment, pour qui, avec quels outils. Ne portez aucun jugement à ce stade.

**Étape 2 : Formuler la problématique**
Transformez votre description en question. Formule test : *« Dans quelle mesure [dispositif] parvient-il à [objectif] alors que [tension/contrainte] ? »*

**Étape 3 : Identifier les angles critiques**
Pour chaque aspect du dispositif, demandez-vous :

- Qu'est-ce que ça résout ?
- Qu'est-ce que ça laisse de côté ?
- Pour qui ça fonctionne ? Pour qui ça ne fonctionne pas ?
- Comment ça se compare à d'autres approches ?

**Étape 4 : Répartir le volume**

| Section          | Volume | Contenu                                        |
| ---------------- | ------ | ---------------------------------------------- |
| Introduction     | ~10 %  | Accroche + contexte + problématique + annonce  |
| Description      | ~50 %  | Présentation fidèle et détaillée du dispositif |
| Analyse critique | ~40 %  | Forces, faiblesses, mise en contexte           |
| Conclusion       | ~10 %  | Synthèse + ouverture                           |

## 4. Vérifications avant de rédiger

- [ ] Mon sujet porte sur **un dispositif identifiable** (pas une généralité)
- [ ] Ma moitié descriptive est **factuelle et sourcée** (chiffres, captures, citations)
- [ ] Mon analyse s'appuie sur **au moins 3 références théoriques**
- [ ] J'ai au moins **une comparaison** avec un autre dispositif (canadien ou international)
- [ ] Ma problématique est une **question ouverte** (pas oui/non)
- [ ] J'ai identifié **où je vais insérer des liens hypertextes** (notices, normes, articles)

## 5. Outils pratiques

- **Gestion bibliographique :** Zotero (gratuit, export auteur-date automatique)
- **Écrire en Markdown** : Zettler, Typora

## 6. Erreurs fréquentes à éviter

- décrire sans jamais questionner. Votre article n'est pas une plaquette de communication.
- parler de concepts théorique sans les ancrer dans le dispositif concret.
- un article sur la médiation culturelle qui ne parle jamais de *documentation* (métadonnées, inventaire, fiches-objets, gestion des données).
- citer un auteur sans avoir lu le texte. En cas de doute, citez la source secondaire explicitement.
